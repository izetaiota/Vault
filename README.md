# Vault

Vault 是个人亲测精选的工具宝库，归集工具、脚本、在线服务与优质资源。拒绝泛收，只沉淀高效实用内容，支持随时检索复用。

## 收录标准

严格遵循「宁缺毋滥」原则，所有收录内容均满足：

- **亲测可用**：经过实际使用验证，功能完整、体验流畅
- **效率优先**：能够解决具体问题、切实提升工作效率
- **稳定低扰**：优先选择长期维护、无广告捆绑的纯净方案
- **去重择优**：同类工具仅保留最优 1-2 款，不做冗余堆砌

## 分类目录

### AI 工具集

覆盖大语言模型、图像生成、效率辅助等各类 AI 应用，包含在线服务、桌面客户端、浏览器插件与本地化部署方案，只收录实测稳定、能切实提升生产力的优质选项。

### 网络与访问工具

收录网络访问相关的客户端、节点方案与配套工具，同时涵盖 DNS 优化、网络调试等通用网络工具，保障稳定的跨境资源访问与网络使用体验。

### 桌面效率工具

涵盖系统增强、文件管理、效率启动器等桌面端工具，优化日常操作流程，减少重复机械操作。

### 开发工具集

包含编辑器插件、命令行工具、调试与部署套件，覆盖前后端开发、运维、数据库等常用技术场景。

### 在线服务

精选无需安装、开箱即用的在线工具与站点，涵盖格式转换、数据处理、资源检索、信息查询等轻量通用需求。

### 脚本与自动化

收纳自用脚本、工作流配置与自动化方案，可替代批量处理、定时执行等重复性工作。

### 素材与资源

沉淀优质文档、图标素材、模板库等资源类内容，作为创作与开发的常备素材库。

## 使用说明

1. 可按分类目录逐级检索，快速定位对应场景的工具与资源
2. 每个条目均标注核心用途、适用场景与使用提示，降低试错成本
3. 支持通过站点搜索功能，按关键词直接查找目标内容

## 更新说明

- 仓库内容不定期更新，所有新增内容均经过实测验证后同步
- 定期清理失效、过时的工具与资源，持续保持仓库内容的可用性
- 分类调整与重要更新会通过提交记录标注，便于追溯变更

## 本地开发

站点基于 [VitePress](https://vitepress.dev/zh/) 搭建，需要 Node.js 22 及以上版本。

```bash
npm install
npm run docs:dev
```

启动后访问 <http://localhost:5173/Vault/>。

| 命令 | 说明 |
| --- | --- |
| `npm run docs:dev` | 启动本地开发服务器，支持热更新 |
| `npm run docs:build` | 构建生产版本，输出到 `docs/.vitepress/dist` |
| `npm run docs:preview` | 本地预览构建结果 |

## 部署

推送到 `master` 分支后，[GitHub Actions](.github/workflows/deploy.yml) 会自动构建站点并发布到 GitHub Pages。
