# iconfont

[iconfont](https://www.iconfont.cn/) 是阿里巴巴体验团队维护的矢量图标与插画资源库：数百万个图标由设计师上传共享，支持按关键词搜索、在线换色调尺寸、SVG/PNG 多格式下载与图标字体/Symbol 代码引用。

## 核心功能

- 海量矢量图标检索，按风格、颜色、流行度筛选
- 在线改色、改尺寸后下载 SVG / PNG
- 「我的项目」：图标加入购物车后批量生成 iconfont 字体或 Symbol，前端直接引用
- 插画库与动效库，同账号统一管理

## 适用场景

- 前端开发找图标：统一风格批量引用
- 文档配图、PPT 图标素材速取

## 使用提示

- 注意图标的授权类型，商用前确认可商用范围
- 引用图标推荐 Symbol 方式，支持多色且按需加载
