# TNT（tntv2.net）

[TNT](https://www.tntv2.net/auth/register?code=c3v1w6) 是个人长期在用的代理订阅服务（机场），基于 SSPanel 搭建：邮箱注册、在线购买套餐、获取订阅链接，导入客户端即可使用。注册建议使用真实邮箱，站点提供在线客服。

## 使用流程

1. **注册**：打开[注册页](https://www.tntv2.net/auth/register?code=c3v1w6)（邀请码已带在链接里），用常用邮箱注册
2. **购买套餐**：登录后在「商店」选择套餐，按需购买
3. **获取订阅**：在用户中心复制「订阅链接」（一键导入或手动添加均可）
4. **导入客户端**：把订阅链接填进代理客户端，更新订阅后选择节点使用

## 客户端建议

| 平台 | 推荐 |
| --- | --- |
| Windows | Clash Verge、v2rayN |
| macOS | Clash Verge、Surge |
| iOS | Shadowrocket（需外区账号购买） |
| Android | v2rayNG、ClashMeta |

## 注意事项

- **订阅链接等于账号凭证**，泄露会被冒用流量，不要外发
- 套餐价格、节点列表与线路调整以[官网](https://www.tntv2.net/)实时信息为准
- 机场服务有时效性，遇到不可用先更新订阅、切换节点，仍不行看官网公告
- 建议同时保留一个备用机场或自建方案，避免单点依赖
