# Claude

[Claude](https://claude.ai/) 是 Anthropic 推出的 AI 对话助手，以长上下文、严谨的推理和高质量的代码输出著称。Artifacts 功能可以把生成的代码、文档直接渲染成可预览的成品。

## 核心功能

- 超长上下文对话，适合整本书/整个项目的分析与问答
- 代码生成与重构，Artifacts 实时预览网页、代码结果
- 项目（Projects）功能：沉淀资料与自定义指令，团队化使用
- 支持文件上传、图像识别与联网搜索

## 适用场景

- 大块代码的阅读、解释与改造
- 长文档研读、材料整理与结构化输出

## 使用提示

- 同样需要核验事实性内容
- 复杂任务建议先给清晰的结构与示例，输出质量差异明显
