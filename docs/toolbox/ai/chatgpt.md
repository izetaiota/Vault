# ChatGPT

[ChatGPT](https://chatgpt.com/) 是 OpenAI 推出的通用 AI 对话助手，基于 GPT 系列大模型，是目前使用最广的 AI 应用之一。支持网页与官方客户端，免费可用，付费解锁更强的模型与更高额度。

## 核心功能

- 多轮对话问答、写作润色、翻译总结
- 代码生成与解释，支持上传文件分析（PDF、表格、图片）
- 图像生成（内置 DALL·E）与语音对话
- 自定义 GPTs、对话记忆与项目归类

## 适用场景

- 日常问答、资料整理、文案与邮件撰写
- 编码辅助：解释报错、生成样例代码、重构建议

## 使用提示

- 涉及事实的数据要自行核验，模型可能一本正经地胡说
- 长文档处理优先上传文件而非粘贴，减少格式丢失
