# Hugging Face

[Hugging Face](https://huggingface.co/) 是全球最大的开源 AI 社区与模型托管平台：数十万个开源模型、数据集和 Space 应用在此沉淀，是寻找、试用、部署开源大模型的第一入口。

## 核心功能

- **Models**：按任务（文本、图像、音频、多模态）检索开源模型，附模型卡与在线体验
- **Datasets**：海量公开数据集，可在线预览与流式加载
- **Spaces**：社区部署的在线演示应用，免环境直接试用
- **Transformers 库**：几行代码加载推理主流开源模型的事实标准

## 适用场景

- 选型开源模型：对比榜单、看模型卡、直接试跑 Demo
- 学习与实践：跑通官方示例，跟进社区最新开源进展

## 使用提示

- 优先看模型卡的许可协议，商业使用注意限制
- Spaces 演示可能排队或失效，正式使用建议本地或自托管部署
