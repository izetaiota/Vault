# Everything

[Everything](https://www.voidtools.com/zh-cn/) 是 Windows 平台的本地文件搜索工具：启动时对 NTFS 卷建立文件名索引，之后搜索近乎即时出结果，远快于系统自带搜索。免安装版可放 U 盘随身携带。

## 核心功能

- 文件名即时搜索，支持通配符、正则表达式与多关键词
- 按大小、日期、属性过滤，可保存常用筛选为书签
- HTTP/FTP/ETP 服务器模式，局域网内远程检索
- 命令行接口与快捷键呼出（默认 `Win + S` 可自定义）

## 使用提示

- 仅索引文件名，不检索文件内容；需要全文搜索时配合其他工具
- 索引基于 NTFS USN 日志，FAT32/exFAT 卷支持有限
- 首次启动建索引很快，文件变动实时更新，几乎无感
