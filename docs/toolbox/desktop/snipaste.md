# Snipaste

[Snipaste](https://zh.snipaste.com/) 是 Windows 平台的截图与贴图工具：截图自动识别元素边界、可精确到像素；「贴图」功能把截图或剪贴板内容直接钉在桌面最上层，写文档、对照参考时特别好用。免费供个人使用。

## 核心功能

- 截图：自动窗口检测、像素级微调、取色、标注（画笔/文字/马赛克/箭头）
- 贴图：截图钉在屏幕任意位置，可缩放、半透明、鼠标穿透
- 剪贴板内容（文字、图片）直接转为贴图
- 自定义快捷键（默认 `F1` 截图、`F3` 贴图）

## 使用提示

- 需要以管理员身份运行才能截取提权窗口
- 贴图支持滚轮缩放、`Tab` 键鼠标穿透，写文档对照利器
