# awesome-mac

[awesome-mac](https://github.com/jaywcjlove/awesome-mac) 是 GitHub 上最全面的 macOS 软件资源汇总之一（119k+ star，持续维护），按类别系统整理优质 Mac 软件：开发工具、编辑器、效率工具、设计产品、终端工具、浏览器插件等，每类精选若干最优选择。中文版为 [README-zh.md](https://github.com/jaywcjlove/awesome-mac/blob/master/README-zh.md)。

## 内容结构

按场景分类，主要涵盖：

- 开发者工具：IDE、编辑器、版本控制、API 调试、数据库客户端
- 效率工具：启动器、剪贴板管理、窗口管理、菜单栏工具
- 设计与图像、音频视频、阅读写作
- 终端与命令行工具、虚拟机与容器
- 浏览器插件、云存储与同步

## 适用场景

- 新入手 Mac，需要一份按场景选软件的清单
- 找某类工具（如 GIF 录屏、Markdown 编辑器）时横向对比选型

## 使用提示

- 列表以开源与免费方案居多，付费软件会标注
- 同类工具一般列出多个候选，结合自己习惯选一个即可，避免堆砌
