# Excalidraw

[Excalidraw](https://excalidraw.com/) 是开源的在线白板工具，主打手绘风格：流程图、架构图、示意图随手画，默认样式即好看，免登录打开就能用，文件保存在本地浏览器。

## 核心功能

- 手绘风图形：方框、箭头、连线、文本、草图库
- 实时协作：分享链接多人同时编辑（端到端加密）
- 导出 PNG / SVG，支持暗色主题与中文界面
- 海量社区素材库，可直接拖入现成的组件图形

## 适用场景

- 快速画架构图、流程图给同事看，不需要专业绘图软件的严谨
- 会议讨论时的草稿白板

## 使用提示

- 画布数据默认存浏览器本地，重要内容记得导出文件备份
- VS Code 有同名插件，编辑器内直接画图嵌入文档
