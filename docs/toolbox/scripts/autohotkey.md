# AutoHotkey

[AutoHotkey](https://www.autohotkey.com/) 是 Windows 平台免费开源的自动化脚本语言：自定义热键、文本替换、窗口操作、模拟键鼠，能把日常重复操作写成脚本一键完成。当前主推语法更现代的 v2 版本。

## 核心功能

- 热键与热字串：任意按键映射为操作，输入缩写自动展开为长文本
- 窗口管理：按标题/类别激活、移动、置顶窗口
- 键鼠模拟与宏：批量执行点击、输入等序列
- 可编译为独立 exe，无环境分发

## 适用场景

- 高频短语、签名、地址的自动展开
- 给没有快捷键的软件绑上快捷键
- 重复性界面操作固化为脚本

## 使用提示

- 新脚本建议直接用 v2 语法，网上旧示例多为 v1，迁移需注意差别
- 改键类脚本建议放开机自启，配合 `#Requires AutoHotkey v2.0` 声明版本
